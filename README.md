# AI HALAL INVESTOR LITE

المشروع التعليمي مكتمل عبر أربع مراحل. هذه النسخة لا تنفذ أوامر ولا تتصل فعلياً بوسيط ولا تمنح الذكاء الاصطناعي صلاحية القرار.

## أوضاع التشغيل

- **DRY-RUN:** الافتراضي؛ لا أوامر ولا اتصالات وساطة، ويعمل التحليل والتقرير محلياً.
- **LIVE-CONFIRM:** انتقال نظري مقيد بمدخلات مراجعة ووثائق مطابقة؛ لا يوجد تنفيذ وسيط في هذه النسخة.
- **AUTO:** معطل وتصريحه غير مقبول في هذه المرحلة، حتى بعد التدقيق الخارجي.

## أزرار السلامة

أنشئ ملف `KILL` لإيقاف الوضع وإعادة الواجهة إلى DRY-RUN:

```sh
termux-setup-storage
touch KILL
```

احذف الملف يدوياً فقط بعد المراجعة:

```sh
rm -f KILL
```

## متغيرات الوسيط

لا تبث مفاتيحاً إلى Git. عند الحاجة اللاحقة، استخدم متغيرات البيئة فقط:

```env
BROKER_ENABLED=0
BROKER_API_KEY=
BROKER_API_SECRET=
BROKER_BASE_URL=
TERMUX_NOTIFICATIONS=0
```

لا يستخدم التطبيق مفاتيح وسيط ويظل حظر التنفيذ ثابتاً.

## إشعارات Termux

تدعم واجهة الإشعار بنية حالة فقط ولا تشغل termux-notification في هذه النسخة. إن أردت التفعيل مستقبلاً، يجب ترخيصه ومراجعته، ولا يحل محل الرقابة اليدوية.

## المساعد الذكي

لا يوجد أي تكامل AI أو صلاحية للقرار والتنفيذ. التقارير محلية وحتمية قدر الإمكان.

## التشغيل والاختبار

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python run.py
pytest -q
```

لا تعرض الخادم على الإنترنت. لا يعد المشروع نصيحة استثمارية أو فتوى شرعية ولا ضماناً للربح.
