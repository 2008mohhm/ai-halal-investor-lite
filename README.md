# AI HALAL INVESTOR LITE

مشروع تعليمي خفيف بلغة Python لـ Android/Termux. لا يضمن أرباحاً ولا يصدر أحكاماً شرعية أو توصيات مخصصة.

## المرحلة 3

تضيف هذه المرحلة:

- اختبار خلفي خارج العينة بنسبة 75/25 واتجاهاً واقعي الشراء والاحتفاظ كمقياس.
- حدود مخاطر ثابتة 10% لكل مركز تعليمياً ووقف خسارة 8% ووقف متحرك 10% في المحرك الخلفي فقط.
- زر وخدمة إيقاف طارئ عبر ملف `KILL`، وملف الإيقاف مستثنى من Git.
- تقارير يومية وأسبوعية وشهرية عربية عبر واجهة/JSON.
- اختبارات بدون إنترنت؛ لا توجد واجهة لوسيط ولا حقن مفاتيح ولا أوامر شراء أو بيع.

## التشغيل

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

لا تعرض الخادم على الإنترنت، ولا تضع مفاتيح وسيط في المستودع. قم بإنشاء ملف `KILL` لإيقاف المحرك من الطرف المحلي:

```sh
touch KILL
```

قم بإزالة الإيقاف محلياً فقط بعد مراجعة المخاطر:

```sh
rm -f KILL
```

الاختبار الخلفي والنتائج التعليمية قد تكون مضللة إذا كانت البيانات انتقائية أو متأخرة. راجع الشيفرة وقارن خارج العينة، ولا تتداول على أساس هذا البرنامج.
