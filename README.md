# AI HALAL INVESTOR LITE

مشروع تعليمي خفيف لـ Android/Termux لتحليل أسهم من قائمة يحددها المستخدم. لا يضمن الأرباح، ولا يصدر أحكاماً شرعية أو توصيات استثمارية مخصصة.

## الحالة الحالية

**المرحلة 1 من 4: أساس المشروع.** تتضمن هذه المرحلة بنية Flask، وقائمة بيضاء أولية، وتهيئة SQLite، وواجهة عربية بسيطة، واختبارات محلية. لا توجد حالياً بيانات سوق أو استراتيجية تداول أو اتصالات وسيط أو أوامر تداول؛ لا تستخدم المشروع للتداول الحقيقي.

## القائمة الأولية

توجد الرموز الـ18 وأسماؤها في `config/watchlist.json`. القائمة إعداد ثابت يقرأه التطبيق ولا يوفر التطبيق واجهة لتعديله. لا يُقبل رمز غير موجود في القائمة. تغيير القائمة يتطلب تعديل ملف الإعداد يدوياً من المستخدم.

مرجع التصفية وتاريخ الاعتماد الواردان في ملف القائمة معلومات زوّد بها المستخدم، ولم يتم التحقق منهما بشكل مستقل. لا يمثل وجود سهم في القائمة فتوى أو ضماناً باستمرارية التوافق الشرعي؛ على المستخدم إجراء التحقق المناسب بنفسه.

## تشغيل محلياً أو في Termux

```sh
pkg install python
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

ثم افتح `http://127.0.0.1:5000` على الهاتف. لا تعرض المنفذ على الإنترنت. أنشئ قيمة `SECRET_KEY` محلية عشوائية قبل أي توسعة للواجهة. ملف `.env` وقاعدة البيانات وملف `KILL` مستثناة من Git.

## الاختبارات

```sh
pytest -q
```

الاختبارات لا تحتاج اتصالاً بالإنترنت أو حساب وسيط.

## مراحل العمل

1. الأساس والبنية الآمنة (هذه المرحلة).
2. استيراد/تطبيع بيانات السوق والتحليلات الفنية وكشف الشذوذ.
3. الاختبار الخلفي والتقارير وإدارة المخاطر.
4. أوضاع التشغيل والربط الاختياري بالوسيط والإشعارات والمراجعة النهائية.

لن تُفعّل أوامر التداول الحقيقية إلا بعد بناء الضوابط المطلوبة واختبارها؛ الوضع الافتراضي المقصود DRY-RUN.
