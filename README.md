# AI HALAL INVESTOR LITE

مشروع تعليمي خفيف لـ Android/Termux لتحليل أسهم من قائمة يحددها المستخدم. لا يضمن الأرباح، ولا يصدر أحكاماً شرعية أو توصيات استثمارية مخصصة.

## الحالة الحالية

**المرحلة 2 من 4 مكتملة: أساس المشروع وتحليل بيانات يومية اختياري.** يتضمن المشروع قائمة بيضاء أولية لا يمكن تعديلها عبر التطبيق، وتخزين SQLite، واستيراد بيانات يومية اختيارياً من Stooq، ومؤشرات فنية مكتوبة بـPython الصافي، وفحص جودة البيانات، ومرشح أساسيات متشدد، وتصنيف حالة السوق وأربع قواعد استراتيجية ثابتة. لا توجد اتصالات وسيط أو أوامر تداول أو تنفيذ آلي.

## القائمة الأولية

توجد الرموز الـ18 وأسماؤها في `config/watchlist.json`. القائمة إعداد ثابت يقرأه التطبيق ولا يوفر التطبيق واجهة لتعديله. مرجع التصفية وتاريخ الاعتماد الواردان معلومات زوّد بها المستخدم ولم يتم التحقق منهما بشكل مستقل؛ ليست القائمة فتوى أو ضماناً باستمرارية التوافق الشرعي.

## التشغيل في Termux

```sh
pkg install python
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

ثم افتح `http://127.0.0.1:5000`. لا تعرض المنفذ على الإنترنت. لتحديث الأسعار، شغّل الاتصال الخارجي يدوياً (يحتاج إنترنت):

```sh
python -m investor.sync_market --symbol AAPL --symbol MSFT
```

بدون `--symbol` سيحاول تحديث كامل القائمة. المصدر الخارجي مجاني لكنه ليس مضمون التوفر أو الدقة، وقد يفرض شروط استخدام/تأخير. تحقق من البيانات قبل الاعتماد عليها. فشل الجلب لا يُنشئ بيانات بديلة.

## تحليل البيانات

- كشف صفوف OHLCV غير الصالحة والتحركات اليومية الأكبر من 20%؛ أي شذوذ يمنع إصدار إشارات الاستراتيجيات.
- SMA 20/50، RSI 14، ATR 14، وتصنيف اتجاه مبني على SMA 20/50.
- أربع قواعد ثابتة: تقاطع اتجاه SMA، ارتداد RSI دون 30، اختراق أعلى 20 إغلاقاً، وتراجع قريب من SMA20 في اتجاه صاعد. نتائجها `LONG_WATCH` تعليمية فقط وليست أوامر أو توصيات.
- المرشح الأساسي مغلق افتراضياً. لا تصدر الإشارات إلا بعد إدخال أساسيات موثقة يدوياً. حد الدين/حقوق الملكية 0.30 قيمة تعليمية ثابتة وليس معياراً شرعياً.
- شاشة التحليل و`/api/analysis/<symbol>` للقراءة فقط. الرمز خارج القائمة يُرفض.
